About QuickNotes

QuickNotes is a simple app for jotting down ideas the moment you think of them. It keeps your notes on one page so you never have to dig through messy paper or scattered apps to find what you wrote.

How to use QuickNotes

  1. Open QuickNotes in your browser.
  2. Click the note input box and type what you want to remember.
  3. Press "Add Note" (or hit Enter) to save it to your list.
  4. Check back later and read through your notes anytime.

Features

  • Fast, distraction-free note entry
  • Keyboard shortcuts for common actions
  • Clean, readable layout
  • Works in any modern browser

Keyboard shortcuts

Shortcut Action
Enter Add the note
Ctrl + S Save the file in VS Code
Ctrl + Z Undo the last change
